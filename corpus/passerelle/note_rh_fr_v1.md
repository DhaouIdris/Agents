# Réexamen des demandes — note interne RH

Document entièrement synthétique. Version 1 publiée le 1er avril 2026.
Diffusion pédagogique simulée : groupe RH uniquement.

## Examen interne

En cas de désaccord sur une demande de télétravail, le gestionnaire RH consulte
le motif du responsable et les contraintes de service avant de proposer un réexamen.
Cette note ne crée pas un droit automatique à une dérogation.

## Canal de coordination

Le code fictif RH-REVUE désigne le canal interne de coordination des gestionnaires RH.
Ce code sert uniquement au scénario pédagogique et ne correspond à aucun service réel.

## Données individuelles

Cette note ne contient aucune donnée personnelle réelle ni décision concernant un agent.
